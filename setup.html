🔐 Supabase সেটআপ গাইড

আপনার GitHub Pages সাইটের জন্য নিরাপদ লগইন সিস্টেম কনফিগার করুন

1 Supabase প্রজেক্ট তৈরি করুন

  • supabase.com এ যান
  • Google বা GitHub দিয়ে সাইন আপ করুন (বিনামূল্যে)
  • "New Project" বাটনে ক্লিক করুন
  • আপনার প্রজেক্ট নাম লিখুন (যেমন: "tuhin-profile")
  • একটি শক্তিশালী ডাটাবেস পাসওয়ার্ড সেট করুন (গুরুত্বপূর্ণ!)
  • একটি অঞ্চল নির্বাচন করুন
  • "Create new project" এ ক্লিক করুন এবং অপেক্ষা করুন (~2 মিনিট)

2 API কী খুঁজে পান

  • Supabase ড্যাশবোর্ডে লগইন করুন
  • বাম দিকে "Settings" → "API" তে ক্লিক করুন
  • নিম্নলিখিত দুটি কী খুঁজে পান:
    • Project URL (এটি আপনার Supabase URL)
    • anon public (এটি আপনার Anon Key)
⚠️ গুরুত্বপূর্ণ: শুধুমাত্র anon public কী ব্যবহার করুন। কখনও service_role কী GitHub-এ রাখবেন না!

3 আপনার সাইটে কী কনফিগার করুন

✅ সফলভাবে সংরক্ষিত! আপনি এখন লগইন পৃষ্ঠায় যেতে পারেন।
💡 নোট: এই কীগুলি শু���ুমাত্র আপনার ব্রাউজারে localStorage-এ সংরক্ষিত থাকে। GitHub-এ কখনও সংরক্ষিত হয় না।

4 Supabase-এ Authentication সক্ষম করুন

  • Supabase ড্যাশবোর্ডে ফিরে যান
  • বাম দিকে "Authentication" মেনুতে ক্লিক করুন
  • "Providers" ট্যাব চেক করুন (Email/Password সাধারণত চালু থাকে)
  • নিশ্চিত করুন যে "Email/Password" সক্ষম আছে

5 প্রথম ব্যবহারকারী তৈরি করুন

  • Supabase ড্যাশবোর্ড → "Authentication" → "Users" এ যান
  • "Add user" বাটনে ক্লিক করুন
  • একটি ইমেইল অ্যাড্রেস এবং শক্তিশালী পাসওয়ার্ড লিখুন
  • "Create user" ক্লিক করুন
  • এখন আপনি এই ইমেইল এবং পাসওয়ার্ড দিয়ে লগইন করতে পারবেন
💡 সুপারিশ: Email confirmation চালু করলে, নতুন ব্যবহারকারীদের তাদের ইমেইল যাচাই করতে হবে। শুরুতে এটি বন্ধ রাখতে পারেন।

6 লগইন পরীক্ষা করুন

  • লগইন পৃষ্ঠাে যান
  • আপনার ইমেইল এবং পাসওয়ার্ড লিখুন
  • "লগইন করুন" ক্লিক করুন
  • সফল হলে, আপনি প্রোফাইল পৃষ্ঠায় পুনঃনির্দেশিত হবেন

🔒 নিরাপত্তা পরামর্শ

  • কখনও service_role কী GitHub-এ রাখবেন না
  • শুধুমাত্র anon public কী ব্যবহার করুন
  • নিয়মিত Supabase সিকিউরিটি রিভিউ করুন
  • শক্তিশালী পাসওয়ার্ড ব্যবহার করুন
  • আপনার ডাটাবেস পাসওয়ার্ড শেয়ার করবেন না
