🛠️ সম্পূর্ণ সেটআপ নির্দেশাবলী

ধাপ 1: Supabase অ্যাকাউন্ট তৈরি করুন

  1. supabase.com পরিদর্শন করুন
  2. Google বা GitHub ব্যবহার করে বিনামূল্যে সাইন আপ করুন
  3. "New Project" ক্লিক করুন
  4. প্রজেক্ট নাম লিখুন (যেমন: tuhin-profile)
  5. একটি শক্তিশালী ডাটাবেস পাসওয়ার্ড সেট করুন
  6. "Create new project" ক্লিক করুন এবং ~2 মিনিট অপেক্ষা করুন

ধাপ 2: API কী পান

  1. Supabase ড্যাশবোর্ডে যান
  2. বাম মেনু থেকে "Settings" → "API" ক্লিক করুন
  3. এই দুটি কী খুঁজুন:
    • Project URL (আপনার Supabase URL)
    • anon public (আপনার Anon Key)
  4. এই কীগুলি কপি করুন

ধাপ 3: কীগুলি কনফিগার করুন

  1. সেটআপ পৃষ্ঠা খুলুন
  2. আপনার Supabase Project URL পেস্ট করুন
  3. আপনার Anon Public কী পেস্ট করুন
  4. "সংরক্ষণ করুন" ক্লিক করুন
  5. "পরীক্ষা করুন" ক্লিক করে সংযোগ যাচাই করুন

ধাপ 4: প্রথম ব্যবহারকারী তৈরি করুন

  1. Supabase ড্যাশবোর্ড → "Authentication" → "Users" এ যান
  2. "Add user" বাটনে ক্লিক করুন
  3. একটি ইমেইল এবং শক্তিশালী পাসওয়ার্ড দিন
  4. "Create user" ক্লিক করুন

ধাপ 5: লগইন পরীক্ষা করুন

  1. লগইন পৃষ্ঠা খুলুন
  2. আপনার ইমেইল এবং পাসওয়ার্ড লিখুন
  3. "লগইন করুন" ক্লিক করুন
  4. সফল হলে, প্রোফাইল পৃষ্ঠায় পুনঃনির্দেশিত হবেন

🔐 নিরাপত্তা তথ্য

⚠️ গুরুত্বপূর্ণ: কখনও আপনার service_role কী বা ডাটাবেস পাসওয়ার্ড GitHub-এ রাখবেন না!

নিরাপদ অনুশীলন:

  • শুধুমাত্র anon public কী ব্যবহার করুন
  • কখনও service_role কী প্রকাশ করবেন না
  • কীগুলি শুধুমাত্র localStorage-এ সংরক্ষিত (GitHub-এ নয়)
  • শক্তিশালী পাসওয়ার্ড ব্যবহার করুন (কমপক্ষে 12 অক্ষর)
  • নিয়মিত Supabase নিরাপত্তা পর্যালোচনা করুন
ℹ️ কীভাবে কাজ করে: আপনার Supabase কীগুলি আপনার ব্রাউজারের localStorage-এ সংরক্ষিত থাকে। GitHub সংরক্ষণাগারে কখনও সংরক্ষিত হয় না, তাই সম্পূর্ণ নিরাপদ।

🔧 সমস্যা সমাধান

❌ "Supabase configuration not found" বার্তা পাচ্ছেন?

  • সেটআপ পৃষ্ঠা খুলুন
  • আপনার Supabase Project URL পেস্ট করুন
  • আপনার Anon Public কী পেস্ট করুন
  • "সংরক্ষণ করুন" ক্লিক করুন

❌ "Invalid login credentials" বার্তা পাচ্ছেন?

  • আপনার ইমেইল এবং পাসওয়ার্ড সঠিক কিনা পুনরায় চেক করুন
  • Supabase ড্যাশবোর্ডে যান এবং ব্যবহারকারী বিদ্যমান কিনা যাচাই করুন
  • নিশ্চিত করুন যে ব্যবহারকারী Email/Password দিয়ে তৈরি করা হয়েছে

❌ "Supabase connection failed" বার্তা পাচ্ছেন?

  • আপনার Supabase URL সঠিক কিনা পুনরায় চেক করুন
  • আপনার Anon Key সঠিক কিনা পুনরায় চেক করুন
  • Supabase প্রজেক্ট সক্রিয় এবং চলমান কিনা নিশ্চিত করুন
  • ব্রাউজার কনসোল খুলুন (F12) এবং ত্রুটি বার্তা দেখুন

❌ সেটআপ পৃষ্ঠা কাজ করছে না?

  • আপনার ব্রাউজার ক্যাশ সাফ করুন (Ctrl+Shift+Delete)
  • পৃষ্ঠা রিফ্রেশ করুন (F5)
  • অন্য ব্রাউজার চেষ্টা করুন

📄 পৃষ্ঠা বিবরণ

1. index.html - হোম পৃষ্ঠা

  • প্রথম পৃষ্ঠা যা ব্যবহারকারী দেখেন
  • প্রোফাইল তথ্য প্রদর্শন করে
  • কোনো লগইন প্রয়োজন নেই

2. login.html - লগইন পৃষ্ঠা

  • ইমেইল/ব্যবহারকারী নাম এবং পাসওয়ার্ড ইনপুট
  • Supabase দ্বারা প্রমাণীকরণ
  • সফল লগইনে প্রোফাইল পৃষ্ঠায় রিডিরেক্ট
  • সুন্দর ত্রুটি বার্তা প্রদর্শন

3. profile.html - সুরক্ষিত প্রোফাইল

  • লগইন ছাড়া অ্যাক্সেস করা যায় না
  • তুহিন ফকিরের সম্পূর্ণ প্রোফাইল প্রদর্শন করে
  • Facebook লিঙ্ক অন্তর্ভুক্ত
  • লগআউট বাটন সহ

4. setup.html - সেটআপ সহায়ক

  • Supabase কনফিগারেশন ইন্টারফেস
  • ধাপে ধাপে সেটআপ নির্দেশনা
  • সংযোগ পরীক্ষা টুল

❓ প্রায়শ জিজ্ঞাসিত প্রশ্ন

Q: Supabase কি বিনামূল্যে?

A: হ্যাঁ, Supabase বিনামূল্যে ফ্রি টায়ার প্রদান করে যা সাধারণ ব্যবহারের জন্য যথেষ্ট।

Q: আমার পাসওয়ার্ড নিরাপদ?

A: হ্যাঁ, Supabase শিল্পের মান অনুযায়ী সমস্ত পাসওয়ার্ড এনক্রিপ্ট করে।

Q: আমি কি একাধিক ব্যবহারকারী তৈরি করতে পারি?

A: হ্যাঁ, Supabase ড্যাশবোর্ডে যেকোনো সংখ্যক ব্যবহারকারী তৈরি করতে পারেন।

Q: যদি আমি আমার Supabase URL ভুল করি তাহলে?

A: সেটআপ পৃষ্ঠা খুলুন এবং সঠিক URL দিয়ে আবার সংরক্ষণ করুন।

Q: আমি কি Facebook লিঙ্ক পরিবর্তন করতে পারি?

A: হ্যাঁ, profile.html ফাইলে Facebook URL সম্পাদনা করুন।

Q: মোবাইলে এটি কাজ করবে?

A: সম্পূর্ণভাবে হ্যাঁ, সব ডিভাইসের জন্য সম্পূর্ণ প্রতিক্রিয়াশীল।
